# FGear & FVisual

---

⚠️ **Важно:** Моды являются исключительно клиентскими. Установка на сервер не требуется и не поддерживается.

---

## 📖 О проекте

### ⚙️ FGear
Функциональный модуль, расширяющий возможности взаимодействия с экипировкой и предметами.

| Команда | Описание |
| :--- | :--- |
| `/fgear save [название]` | Сохраняет весь инвентарь. |
| `/fgear del [название]` | Удаляет сохранённый инвентарь. |
| `/fgear list [название]` | Проверяет список сохранённых инвентарей. |

### 🎨 FVisual
Визуальный модуль с упором на кастомизацию HUD (интерфейса).

> 🚧 **Статус:** Функции находятся в разработке. Пока отсутствуют!

---

## 🚀 Установка

1. Установите **Fabric Loader** версии `1.21.11` для соответствующей версии Minecraft.
2. Скачайте `.jar`-файл мода из раздела **Releases**.
3. Поместите файл в папку `.minecraft/mods`.
4. Запустите игру.

### 📋 Зависимости
*   **Fabric API** (обязательно для Fabric-версии).
