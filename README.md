О проекте
FGear и FVisual — клиентские модификации, разработанные командой F-Team для улучшения игрового опыта без нарушения баланса. Оба мода ориентированы на тонкую настройку интерфейса.

Важно: моды являются исключительно клиентскими. Установка на сервер не требуется и не поддерживается.

FGear
Функциональный модуль, расширяющий возможности взаимодействия с экипировкой и предметами.

Функция	Описание
/fgear save [название] - Сохраняет весь инвентарь.
/fgear del [название] - Удалить сохранённый инвентарь.
fgear list [название] - Проверить список сохранённых инвентарей.

FVisual
Визуальный модуль с упором на кастомизацию HUD.

Функция	Описание
Пока отсутствуют!

Установка
Установите Fabric Loader версии 1.21.11 для соответствующей версии Minecraft.

Скачайте .jar-файл мода.

Поместите файл в папку .minecraft/mods.

Запустите игру.

Зависимости
Fabric API (обязательно для Fabric-версии)
